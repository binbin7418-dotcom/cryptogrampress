# CryptogramPress · 验收记录（2026-11-03）

方法：证明输出验收——建一本真书（Mixed，Easy/Medium/Hard 各 2 题），再用独立检查器从**印刷密文本身**复验：检查器自带词型求解器（按最长词优先回溯，与引擎的「候选最少优先」是不同搜索形态、零共享代码；词典为数据共享，口径见下），必须找到恰一个解码且等于印刷引文。

终验结果：**8/8 PASS**（`acceptance_results.txt` 为真跑记录）

- 6 题，长度带 Easy/Medium/Hard 轮转，字母数 [55, 81, 143, 38, 73, 98]
- 每副替换均为真双射且无字母自映射
- 印刷密钥逐题把密文精确解回引文原文
- 独立求解器复验：6/6 密文恰一解码
- 篡改一题（密文里交换两个字母）→ 密钥解码不再等于引文，闸门有牙
- PDF 612×792pt、14 页；整本生成＋验证约 6.3s（含一次性唯一池证明）；固定 seed 可复现

口径纪律（重要）：「恰一解码」是对**内置词典**（1,700+ 常用词＋引文库词汇，源码内可审计）而言的唯一性——文案与 README 均按此口径表述，不夸大为数学唯一。引文库 68 条公有领域引文（归属有争议/现代伪托的已剔除），过唯一性证明的池：Easy 17 / Medium 12 / Hard 6；超池的书以新密钥复用引文（每题证明仍逐题成立），README 已如实写明。

本地包验证：PyInstaller 本机实构建成功（Linux 旁证）。Windows 包由仓库 Actions 构建（待主会话建仓触发）。

样本：`sample_book.pdf`（6 题 Mixed，seed 42，与验收同一本）。
